7.  Degree Theory

Suppose that n≥1n\geq 1, and let f:𝕊n→𝕊nf:\mathbb{S}^{n}\rightarrow\mathbb{S}^{n} be continuous. The map f∗:Hn⁢(𝕊n)→Hn⁢(𝕊n)f_{\ast}:H_{n}(\mathbb{S}^{n})\rightarrow H_{n}(\mathbb{S}^{n}), is a homomorphism ℤ→ℤ\mathbb{Z}\rightarrow\mathbb{Z}, which corresponds to multiplication by an integer, called the degree of ff.

Proposition 7.1.

Suppose n≥1n\geq 1, and f,g:𝕊n→𝕊nf,g:\mathbb{S}^{n}\rightarrow\mathbb{S}^{n} are continuous maps.

  1. 1.

    deg⁡(f∘g)=deg⁡f⁢deg⁡g\deg(f\circ g)=\deg f\deg g.

  2. 2.

    f≃gf\simeq g, then deg⁡f=deg⁡g\deg f=\deg g.

Proof.

Part 1 follows from the fact that taking homologies is a functor, and part 2 from the homotopy invariance of singular homology. ∎

Theorem 7.2.

Let φ:𝕊n→𝕊n\varphi:\mathbb{S}^{n}\rightarrow\mathbb{S}^{n} be continupus. deg⁡φ≠0\deg\varphi\neq 0 implies that φ\varphi is surjective. If deg⁡φ≠(−1)n+1,\deg\varphi\neq(-1)^{n+1}, then φ\varphi has a fixed point.

Proof.

Indeed, for the first statement, if the image of φ\varphi was not all of 𝕊n\mathbb{S}^{n}, then the map φ\varphi would be homotopic to a constant map. This is because if the image misses a point pp, then 𝕊n\{p}\mathbb{S}^{n}\backslash\{p\} is contractible. Thus the map φ\varphi induces a trivial homomorphism which has degreee 0.
Now suppose that ff does not have any fixed points. Let a:𝕊n→𝕊na:\mathbb{S}^{n}\rightarrow\mathbb{S}^{n} denote the antipodal map. Then a∘f≃i⁢da\circ f\simeq id. This is because the image of any point will not be −x-x, so the image a⁢(f⁢(x))a(f(x)) can be traced back to xx via a homotopy on a great circle. This, deg⁡a⁢deg⁡f=deg⁡i⁢d⟹deg⁡f=(−1)n+1\deg a\deg f=\deg id\implies\deg f=(-1)^{n+1} ∎

Theorem 7.3.

The antipodal map α:𝕊n→𝕊n\alpha:\mathbb{S}^{n}\rightarrow\mathbb{S}^{n} is homotopic to the identity iff nn is odd.

Proof.

If n=2⁢k−1n=2k-1 is odd, then an explicit homotopy is given by

H⁢(x,t)=(cos⁡π⁢t⋅x1+sin⁡π⁢t⋅x2,cos⁡π⁢t⋅x2−sin⁡π⁢t⋅x1,⋯,cos⁡π⁢t⋅x2⁢k−sin⁡π⁢t⋅x2⁢k−1)H(x,t)=(\cos\pi t\cdot x_{1}+\sin\pi t\cdot x_{2},\cos\pi t\cdot x_{2}-\sin\pi t% \cdot x_{1},\cdots,\cos\pi t\cdot x_{2k}-\sin\pi t\cdot x_{2k-1})

If n=0n=0, then a⁢l⁢p⁢h⁢aalpha is clearly not homotopic to the identity. If n>0n>0 is even, then deg⁡α=−1\deg\alpha=-1, but deg⁡i⁢d=1\deg id=1 thus proving the theorem. ∎

Theorem 7.4 (Hairy Ball).

There exists a nowhere vanishing vector field on 𝕊n\mathbb{S}^{n} iff nn is odd.

Proof.

Suppose that there exists such a vector field. Then we can use V/|V|V/|V| to construct a homotopy between the antipodal map α\alpha and i⁢did as follows.

H⁢(x,t)=(cos⁡π⁢t)⁢x+(sin⁡π⁢t)⁢V⁢(x)/|V⁢(x)|.H(x,t)=(\cos\pi t)x+(\sin\pi t)V(x)/|V(x)|.

Since V⁢(x)⋅x=0V(x)\cdot x=0 by definition of a vector field and |x|2=|V⁢(x)|2=1|x|^{2}=|V(x)|^{2}=1, we get that the above map is the desired homotopy. Therefore nn must be odd. ∎
